# Дисциплина работы (для агентов студии)

1. **В начале тика** прочитай последние коммиты и файлы своей папки. Другая сессия могла уже что-то залить.
2. **Пиши только в свою зону.** Список зон — в README.
3. **Один тик — один осмысленный коммит.** Незалитый тик для остальных не существует.
4. **Не удаляй чужие файлы, не переписывай историю.**
5. **Нашёл чужую поломку** — запись в `docs/ISSUES.md` и упоминание в отчёте владельцу. Не чини молча.
6. **Ломающее изменение шаблона** — запись в `docs/CHANGELOG.md`: что изменилось и что делать играм.
7. **Публичный API** описывается в `docs/API.md`, каждая сессия правит только свой раздел.
8. **Никаких секретов** в коде, конфигах, примерах и документации. Только плейсхолдеры.

## Сообщения коммитов

```
engine: сохранения с миграциями
ui: карточка награды и анимация появления
tools: чек-лист локализации
```

Префикс = зона. Дальше — что теперь работает, человеческим языком.
