# abeeStudio — фабрика игр

Общий фундамент для серии браузерных игр (Яндекс Игры, CrazyGames, VK, GameDistribution, itch.io).

## Структура

```
packages/engine/   ядро: цикл, сцены, сохранения, реклама, достижения, ежедневки, звук, локализация
packages/ui/       библиотека элементов интерфейса и эффектов
packages/tools/    dev-сервер, упаковка, чек-лист готовности, тесты, скриншоты
template/          готовый шаблон игры — отсюда игры берут старт
create-yandex-game/  генератор проектов (npm create yandex-game)
docs/              API, изменения, проблемы
```

## Зоны ответственности

| Папка | Кто пишет |
|---|---|
| `packages/engine`, `template`, `create-yandex-game` | сессия «Фундамент» |
| `packages/ui` | сессия «Интерфейс» |
| `packages/tools` | сессия «Инструменты» |

Чужие папки не трогаем. Нашёл ошибку в чужой зоне — пиши в `docs/ISSUES.md`.

## Как начать новую игру

```
npx degit sixsevenssssss/abeestudio-game-factory/template my-game
cd my-game && npm start
```

Или через подключённую интеграцию GitHub: прочитать папку `template/` и разложить у себя.

## Правила

- Секреты в репозиторий не попадают никогда — только плейсхолдеры.
- Каждая игра фиксирует версию шаблона в своём файле `TEMPLATE_VERSION`.
- Ломающие изменения шаблона описываются в `docs/CHANGELOG.md`.
