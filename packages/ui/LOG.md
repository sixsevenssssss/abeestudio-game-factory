**Решение — среда исполнения:**
`registry.npmjs.org` возвращает 403 в песочнице — `npm install`, `npx`, скиллы «aislop CLI» и «Playwright MCP» через npx не работают. Рабочий путь для проверки: `pip install playwright` + `python3 -m playwright install chromium`. Проверено вживую: Chromium скачивается, несколько viewport, перехват ошибок консоли, detekt горизонтального переполнения, измерение зон нажатия через `bounding_box()` — всё работает. `check-showcase.py` реализован через этот путь.

**Решение — архитектура компонентов:**
Функции, возвращающие HTMLElement. Никаких фреймворков. Темы через CSS custom properties (класс на `<html>`). Переключение темы одной строкой. Это решение выбрано как простейшее, соответствующее ограничению «чистые ES-модули, без шага сборки».
