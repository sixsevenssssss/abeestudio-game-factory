## [2026-08-03] Тик 1 — src/serve.js

**Сделано:** dev-сервер без внешних зависимостей, package.json с `"type":"module"`, тест-фикстура minimal-game, 24 теста.

**Решения:**
- ES-модули (`"type": "module"` в package.json) — согласованность с игровым кодом, чистые import/export для тестов.
- Функции `parseArgs`, `MIME`, `injectIntoHtml` экспортированы отдельно → юнит-тесты без запуска сервера.
- Сервер запускается только когда файл является точкой входа (`import.meta.url` vs `process.argv[1]`).
- Path traversal: `path.join` нормализует `..`, защитный check по prefix ROOT.
- `fs.watch` с `recursive:true` + fallback на polling (Linux CI).
- Порт 13742 в тестах — нестандартный, не конфликтует с dev-сервером.

**Проверено от противного:**
- `404 для несуществующего файла` — тест ✓
- `403 при path traversal /..%2F..%2Fetc%2Fpasswd` — тест ✓
- Неправильный Content-Type не проходит — проверяется по каждому расширению ✓
