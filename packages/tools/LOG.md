## [2026-08-03] Тик 2 — runner.js + check.js

**Сделано:** инфраструктура чек-листа, 25 тестов, точка входа check.js с автодискаврингом.

**Решения:**
- `runChecks` — последовательный (не параллельный) запуск: детерминированный порядок, проще отлаживать.
- Исключение в fn → `skip`, не `fail`: ошибка в самой проверке не должна давать ложный fail или ложный ok. Три состояния принципиальны.
- `check.js` автоматически загружает все `.js` файлы из `checks/` через dynamic import + pathToFileURL. Добавить новую проверку = добавить файл, без правки check.js.
- `exitCode`: skip ≠ fail. Skip — «не проверено», не блокирует отправку, но честно виден в отчёте. Это намеренное решение: скрыть «нет браузера» за ненулевым кодом — значит либо врать, либо вечно блокировать CI.
- Склонение ruPlural: числа 11–19 обрабатываются отдельно (русское исключение).

**Проверено от противного:**
- Исключение в fn → skip (не fail) ✓
- Неверный статус из fn → skip ✓
- only=несуществующий → пустой массив, exit 0 ✓
- skip → exit 0 (не блокирует) ✓

## [2026-08-03] Внеплановая починка — ложное зелёное при пустом чек-листе

**Поломка:** `check.js` с пустым реестром печатал «✅ ГОТОВО К ОТПРАВКЕ (0 ✔ 0 пропущено)» и возвращал 0. Инструмент, созданный чтобы не пустить непроверенную игру на модерацию, сам выдавал ей зелёное — не проверив ничего. Тот же баг сработал бы позже, когда браузерные проверки массово уходят в skip на машине без Chromium.

**Починка:** четыре вердикта вместо двух. Пустой реестр и «все skip» дают «⚠️ ВЕРДИКТ НЕ ВЫДАН» и код возврата 2. Ноль теперь означает ровно «есть подтверждённые ok и ни одной fail», а не «ошибок не нашлось».

**Причина решения:** ноль — это обещание «проверено, можно заливать». Отдавать его, когда проверок не было, значит врать вызывающему; на этих вердиктах игру отправляют на модерацию, где отказ удваивает кулдаун. «Не знаю» обязано отличаться от «всё хорошо» и в тексте, и в коде возврата.

**Проверено:** 52/52 теста зелёные. Пустой реестр вручную: «ВЕРДИКТ НЕ ВЫДАН», exit 2. Добавлено 6 тестов ровно на этот класс ошибки (пустой реестр, все-skip, ok+skip, fail+skip).

**API.md:** переписаны коды возврата, добавлена таблица вердиктов, статусы команд приведены к правде (готово / каркас / не реализовано) — раньше таблица помечала тиками то, чего нет.
