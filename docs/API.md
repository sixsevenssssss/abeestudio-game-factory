# Публичный API фабрики — оглавление

**Внимание:** этот файл — только оглавление. Чтобы три сессии не конфликтовали при одновременной
работе, каждая зона описывается в своём файле. Правь только свой.

| Зона | Файл | Кто пишет |
|---|---|---|
| Ядро и системы | [api-engine.md](api-engine.md) | сессия «Фундамент» |
| Элементы интерфейса | [api-ui.md](api-ui.md) | сессия «Интерфейс» |
| Команды и проверки | [api-tools.md](api-tools.md) | сессия «Инструменты» |

Общий контракт, от которого нельзя отступать, — в [CONTRACT.md](CONTRACT.md). Он менялся только
владельцем: если тебе кажется, что контракт неверный, пиши в `ISSUES.md`, не переписывай его сам.
