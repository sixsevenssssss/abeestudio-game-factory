# Доска состояния фабрики

Каждая сессия обновляет **только свою строку** в конце тика. Владелец смотрит сюда,
чтобы понять, можно ли запускать игры.

| Зона | Состояние | Готово к использованию | Обновлено |
|---|---|---|---|
| engine | не начато | нет | — |
| ui | не начато | нет | — |
| tools | не начато | нет | — |

Колонка «готово к использованию» переключается в «да» только когда выполнен критерий готовности
из промпта сессии. Для engine это означает: проект создаётся одной командой, открывается в браузере
без ошибок, работают меню, настройки, сохранения, язык, реклама через мок.

## Параллельная работа: на что опираться, пока соседи не готовы

- **ui** не ждёт engine: элементы пишутся против контракта из `CONTRACT.md`, проверяются на витрине.
- **tools** не ждёт engine: команды и проверки пишутся против структуры проекта из `CONTRACT.md`,
  а проверяются сначала на игрушечном проекте-пустышке, потом на настоящем шаблоне.
- **engine** ни от кого не зависит и идёт первым по важности: пока его нет, игры запускать нельзя.
